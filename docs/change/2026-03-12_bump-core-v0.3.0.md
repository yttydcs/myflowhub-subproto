# SubProto：升级 myflowhub-core 到 v0.3.0（对齐 Pipe 抽象重大变更）

## 背景 / 目标
- Core `v0.3.0` 将 `core.IConnection` 从 `RawConn()` 迁移到 `Pipe()`，属于重大变更（Breaking Change）。
- 本仓 `main` 的部分单测已适配 `Pipe()`，但对应模块仍依赖 `myflowhub-core v0.2.1`，导致 `GOWORK=off go test` 编译失败。

目标：
- 将受影响模块的 `myflowhub-core` 依赖升级到 `v0.3.0`，确保 CI/默认模式可测。

## 具体变更
升级以下模块依赖（并更新 `go.sum`）：
- `auth`：`github.com/yttydcs/myflowhub-core v0.2.1` → `v0.3.0`
- `management`：`github.com/yttydcs/myflowhub-core v0.2.1` → `v0.3.0`
- `varstore`：`github.com/yttydcs/myflowhub-core v0.2.1` → `v0.3.0`

## 测试与验证
- `cd auth; GOWORK=off go test ./... -count=1 -p 1` ✅
- `cd management; GOWORK=off go test ./... -count=1 -p 1` ✅
- `cd varstore; GOWORK=off go test ./... -count=1 -p 1` ✅

## 潜在影响
- 模块 `go.mod` 最小依赖已提升到 Core `v0.3.0`；若消费者强制锁定更低 Core 版本将发生冲突。

## 回滚方案
- revert 本次依赖升级提交（同时需回滚此前对测试代码的 `Pipe()` 适配提交，否则测试仍会失败）。
