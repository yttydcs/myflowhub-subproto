## 经验 / 教训摘要
- `flow` 这类单仓 module 不能把 sibling repo `replace` 留在正式发布状态里，否则单仓 clone 与下游 semver 消费都会失真。
- module 当前源码依赖更高 Proto 版本时，必须先抬高 `go.mod` 最低版本，再做 `GOWORK=off` 验证。
